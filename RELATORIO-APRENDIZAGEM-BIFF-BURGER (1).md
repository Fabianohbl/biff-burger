# Relatório de Aprendizagem — Biff Burger

## 1. Objetivo do projeto

O Biff Burger foi desenvolvido como um projeto prático para consolidar os conhecimentos de HTML e CSS, construindo uma página completa, com identidade visual própria, diferentes seções e adaptação para dispositivos móveis.

## 2. Conteúdos estudados no curso

Até o momento, foram estudados:
- Fundamentos de HTML.
- Fundamentos de CSS.
- Flexbox.
- CSS Grid.

## 3. Aplicação prática no projeto

| Conteúdo | Aplicação no Biff Burger |
|---|---|
| HTML | Estruturação da página e de suas seções. |
| HTML semântico | Uso de `header`, `nav`, `main`, `section`, `article` e `footer`. |
| Classes e IDs | Identificação e organização dos elementos HTML. |
| CSS | Estilização dos componentes e das seções. |
| Flexbox | Alinhamento e distribuição de elementos. |
| CSS Grid | Organização dos cartões de produtos. |
| Responsividade | Adaptação do layout para telas menores. |
| Media Queries | Regras específicas para diferentes larguras de tela. |
| Tipografia | Uso de fontes personalizadas. |
| Cores | Identidade visual organizada com variáveis CSS. |

## 4. Técnicas adicionais praticadas

- `:hover` para efeitos visuais.
- `transition` para transições.
- `@font-face` para carregar fontes locais.
- `object-fit` para controlar o ajuste das imagens.
- `aspect-ratio` para definir proporções.
- `clamp()` para tamanhos flexíveis.
- Gradientes lineares e radiais.
- Pseudo-elementos `::before` e `::after`.
- Modais construídos com HTML e CSS, sem JavaScript.
- Atributos `alt` e recursos de acessibilidade.
- Organização do CSS em arquivos separados por seção ou componente.

## 5. Organização e ferramentas

O projeto permitiu praticar a separação de HTML, CSS, imagens e fontes; a organização dos estilos em múltiplos arquivos; o uso do VS Code; o versionamento com Git; e a publicação e atualização do projeto no GitHub.

## 6. Competências praticadas

1. Construir uma página utilizando HTML semântico.
2. Criar layouts com Flexbox e CSS Grid.
3. Organizar uma página em seções independentes.
4. Separar e organizar estilos em arquivos CSS.
5. Trabalhar com imagens, fontes e identidade visual.
6. Adaptar layouts para telas menores.
7. Criar interações visuais e modais sem JavaScript.
8. Versionar e publicar um projeto com Git e GitHub.

## 7. Próximos conhecimentos a desenvolver

Os tópicos abaixo são possibilidades de evolução futura, não funcionalidades já implementadas:
- JavaScript e manipulação do DOM.
- Filtros funcionais para os produtos.
- Carrosséis interativos.
- Menus interativos.
- Integração com formulários.
- Consumo de APIs.
- Back-end e banco de dados.

## 8. Conclusão

O Biff Burger foi um projeto de consolidação dos conhecimentos de HTML e CSS. Durante sua construção, os conceitos estudados foram aplicados em uma interface completa, dividida em seções, com identidade visual própria e preocupação com a adaptação para diferentes dispositivos.

**Observação:** este relatório diferencia os conteúdos identificados como estudados no curso das técnicas adicionais praticadas durante o desenvolvimento. Ele não afirma que todos os recursos adicionais foram ensinados no curso.
